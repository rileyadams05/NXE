# NXE

NXE is a controller-first dashboard for Xbox One and Xbox Series consoles in Developer Mode. It provides a unified game library for supported emulator applications and a console-hosted FTP service managed through the Vortex Prime website.

## Current test build

The repository contains one signed Windows/Xbox test package:

- `NXE Installer 0.2.0.57.appx`

The Windows installation is provided for interface and controller testing before deploying the same UWP package to an Xbox in Developer Mode.

## External game drive setup

Prepare the external drive on a Windows PC **before connecting it to the Xbox**:

1. Format the drive as **NTFS**.
2. Follow the required PowerShell permission procedure in [`Docs/MODERN-XBOX-USB-SETUP.md`](Docs/MODERN-XBOX-USB-SETUP.md).
3. Connect the prepared drive to the Xbox.

NXE only exposes a drive and its games after Windows/Xbox permissions allow the app to read it. The dashboard does not display a fake permission result.

## FTP control

The FTP server runs on the Xbox. NXE displays the server status, the console IP address, and a QR code. Scanning the QR opens the paired Vortex Prime control page, where optional FTP login details can be managed and a failed FTP service can be restarted.

- [Vortex Prime NXE project](https://vortex-prime-emu.com/projects/)
- [NXE FTP control](https://vortex-prime-emu.com/projects/nxe/ftp/)

The control page requires a pairing link generated by NXE. Pairing credentials are not committed to this repository.

## Source layout

- `ModernXbox/Dashboard` — UWP dashboard and runtime integration
- `ModernXbox/Library` — unified game library models, importers, and indexing
- `ModernXbox/Emulators` — supported emulator launch adapters
- `ModernXbox/Shared` — shared modern Xbox code
- `Docs` — setup and architecture documentation

Generated build folders, certificates, and superseded installer packages are intentionally excluded.
