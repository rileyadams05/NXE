# Flat Gamepad Icons

NXE packages the Xbox controller glyphs used by the dashboard footer from:

https://github.com/RobTheFiveNine/flat-gamepad-icons

The source SVG is included as `icons.svg`; the locally packaged `xb_a.svg`,
`xb_y.svg`, and `xb_lb.svg` files are extracted views of the supplied Xbox
groups. The repository README and `LICENSE.md` are retained alongside them.

The footer currently uses the manually extracted local Xbox SVGs supplied for
this NXE build (`xb_a.svg`, `xb_lb.svg`, `xb_y.svg`, and `xb_view.svg`).
